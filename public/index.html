Giải Trình Kỹ Thuật Các Giao Thức Mạng Phục Vụ Bảo Vệ BTL

1. Giao Thức HTTP & SSE (:3000)

• HTTP RESTful: Cung cấp các phương thức chuẩn GET, POST, PUT, DELETE cho phép E-Form thao tác dữ liệu thiết bị viễn trắc.

• Server-Sent Events (SSE): Kênh truyền tải đơn hướng liên tục từ Server đến Client qua kết nối HTTP keep-alive, giúp trang web biến thành "Web Động" cập nhật dữ liệu tự động mà không cần Polling tiêu tốn tài nguyên.

2. Giao Thức FTP Server (:2121)

• Tuân thủ đặc tả RFC 959 sử dụng 2 kênh kết nối: Kênh điều khiển (Control Connection) trên cổng 2121 và Kênh dữ liệu (Data Connection - Passive Mode).

• Phân quyền bảo mật: Hệ thống xác thực bằng lệnh USER và PASS, cô lập tài khoản Guest trong thư mục /public chỉ có quyền Đọc (RETR), tài khoản Admin có toàn quyền Ghi/Xóa (STOR, DELE).

3. Giao Thức SMTP Mail Đa Miền (:2525)

• Tuân thủ đặc tả RFC 5321 thực hiện bắt tay SMTP (HELO/EHLO, MAIL FROM, RCPT TO, DATA, QUIT).

• Hệ thống Đa Miền: Bộ định tuyến SMTP tiếp nhận và phân phối thư cho cả 2 tên miền @iot-network.local và @monitoring-lab.vn, liên kết trực tiếp với cơ chế tự động gửi cảnh báo khi viễn trắc vượt ngưỡng an toàn.
